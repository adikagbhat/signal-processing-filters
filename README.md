# Tactical Signal Enhancement Filters

Python implementation of digital IIR Butterworth filters designed for audio bandpass noise isolation and signal restoration.

## Features
- **IIR Butterworth Implementation:** High-attenuation bandpass and lowpass filtering.
- **Bilinear Transform Mapping:** Stable frequency-response discretization to eliminate aliasing.
- **Denoising Pipeline:** Targeted band separation for noisy communication waveforms.

## Tech Stack
- **Language:** Python 3.8+
- **Libraries:** NumPy, SciPy
